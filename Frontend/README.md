# DukaanAI — Smart Retail & Kirana Management Platform

DukaanAI is an AI-powered retail management web application built for local Indian retailers and kirana store owners. It simplifies daily billing, inventory tracking, khata credit ledger management, payment reconciliation, and business insights.

## Features

- **Dashboard & KPIs**: Real-time sales summary, outstanding customer credit, cash collected, and low stock warnings.
- **Sales & POS Billing**: Quick itemized billing, multi-item cart calculation, cash / UPI / credit split payments.
- **Inventory Management**: Product stock monitoring, low-stock notifications, quantity adjustments, and categorisation.
- **Digital Khata (Udhar Ledger)**: Customer balance tracking, ledger credit/debit records, and reminder triggers.
- **Payment Analytics**: UPI, Cash, and Credit reconciliation.
- **AI Shop Assistant**: Natural language and voice-enabled query interface for immediate answers (e.g., *"Kitna chawal bacha hai?"*, *"Who owes me money?"*, *"Aaj ki kamai kitni hui?"*).
- **Search & Quick Navigation**: Global shortcut (`⌘K` / `Ctrl+K`) for rapid lookup of products and customers.

## Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite 8](https://vite.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Fonts**: Inter (Google Fonts)

## Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Run the development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview the production build
npm run preview
```
